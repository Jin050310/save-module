# 수강시간표 가져오기 도우미 (초기 골격)

학교 수강신청 포털의 신청 내역을 브라우저 안에 저장하고, 에브리타임 페이지에서 과목을 미리 보는 Chrome Extension Manifest V3 프로젝트입니다.

현재 버전은 포털에서 읽기와 에타에서 미리보기까지만 합니다. 에타 시간표에 과목을 자동 등록하거나 저장하지 않습니다.

## VS Code에서 열기

1. 이 폴더를 VS Code에서 엽니다.
2. 아래 포털 주소와 표 구조를 실제 학교 포털에 맞게 수정합니다.
3. Chrome에서 chrome://extensions 를 엽니다.
4. 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드’를 눌러 이 폴더를 선택합니다.
5. 포털과 에타 탭을 새로고침합니다.

## 먼저 바꿔야 하는 설정

### 포털 주소

manifest.json 안의 https://portal.example.edu/*를 실제 수강신청 사이트 주소로 교체합니다. host_permissions와 첫 번째 content_scripts.matches 두 곳을 모두 바꾸세요.

### 포털 시간표 표

portal.js의 CONFIG를 실제 표에 맞춥니다.

- rowSelector: 수강 과목 한 줄을 선택하는 CSS 선택자
- columns.code: 과목 코드가 있는 td의 0부터 시작하는 위치
- columns.name: 과목명이 있는 td의 위치
- columns.meeting: 요일과 시간이 적힌 td의 위치
- columns.location: 강의실 td의 위치

예시 설정은 과목 코드, 과목명, 담당교수, 요일·시간, 강의실 순서의 표를 가정합니다. 실제 포털 표가 다르면 선택자와 열 번호를 수정해야 합니다.

현재 시간 파서는 월 09:00-10:15, 화요일 13:00~14:15 같은 텍스트를 대상으로 합니다. 교시 번호만 표시되는 포털이라면 파서를 추가로 수정해야 합니다.

## 사용 흐름

1. 포털에서 수강신청을 완료하고 저장된 신청 내역 화면으로 이동합니다.
2. 확장 프로그램의 ‘수강시간표 저장’ 버튼을 누릅니다.
3. 에타 시간표 페이지에서 ‘포털 시간표 붙여넣기’ 버튼을 눌러 미리보기를 확인합니다.
4. 더 이상 필요하지 않은 데이터는 미리보기 창에서 ‘저장 데이터 지우기’를 누릅니다.

시간표는 chrome.storage.local을 이용해 이 브라우저 안에 저장하며 외부 서버로 보내지 않습니다.

## 주의

- 실제 수강신청된 과목만 읽는지 먼저 확인하세요.
- 포털 화면 구조가 바뀌면 선택자를 다시 맞춰야 할 수 있습니다.
- 확장 프로그램이 에타 공식 기능을 대체하거나 에타 서버에 직접 데이터를 쓰지는 않습니다.
