# inha-timetable

인하대 수강신청 화면의 표를 복사해 붙여넣으면 JSON/CSV 시간표로 바꿔주는 도구 (MVP 초기 버전).

## 개인정보 규칙
- 학번, 이름, 비밀번호는 읽지도 저장하지도 않는다.
- 실제 학번/이름이 들어 있는 캡처나 텍스트를 저장소에 올리지 않는다. (`samples/`에는 과목 정보만 넣기)

## 폴더 구조
```
inha-timetable/
├── src/
│   ├── timetable_parser.py   # 교시 → 시각 변환, '시간 및 강의실' 해석
│   └── convert.py            # 붙여넣은 표(탭 구분) → JSON/CSV
├── tests/test_parser.py      # 자동 테스트
└── samples/sample_paste.tsv  # 캡처에서 확인한 두 과목
```

## 실행 방법 (Python 3.9 이상, 별도 설치 없음)
프로젝트 폴더에서:

```
python3 -m unittest discover -s tests -v
python3 src/convert.py samples/sample_paste.tsv --semester 2026-2 --format json
python3 src/convert.py samples/sample_paste.tsv --semester 2026-2 --format csv -o out.csv
```

**권장: 강의시간표 PDF** (수강신청 후 받는 '수업시간표'). 요일·시각·강의실을 모두 읽습니다. `pip install pdfplumber`가 필요합니다.
```
python3 src/convert.py 강의시간표.pdf --semester 2026-2
```
PDF에는 성명이 들어 있습니다. 코드는 읽지 않지만, PDF 파일 자체를 저장소에 올리지 마세요. 학수번호·분반은 PDF에 없어서(시간표 밖 강의 제외) 수강신청 확인서와 합쳐야 합니다.

시간표 격자를 복사한 텍스트(첫 줄 `교시/요일`)는 요일과 강의실이 복사 결과에 없어서 요일을 직접 줘야 합니다:
```
python3 src/convert.py samples/sample_grid.txt --semester 2026-2 --days GEB1108-027=화,목 --days CHM1927-008=수
```

## 확인된 것 / 아직 모르는 것
확인됨 (실제 복사 결과: 시간표 격자)
- 과목은 3줄(과목명, 학수번호, 교수)이고 걸친 교시마다 반복됨. 교시별 시각은 `[11:00 ~ 11:30]`로 적혀 있음
- 1~25교시 확인 (25교시 = 21:00~21:30)
- 복사하면 빈 칸의 탭이 사라져 **요일 열을 알 수 없음**. 강의실도 없음

확인됨 (캡처 1장 기준)
- 시간 표기: `수5,6,7,8(5동511)`, `화10,11,12,목10,11,12(60주년-502)`
- 1교시 = 09:00, 교시당 30분 (1~13교시 확인)
- 학수번호에 분반이 합쳐져 있음 (`CHM1927-008`)

미확인 (코드가 '확인 필요' 경고로 표시함)
- 요일마다 강의실이 다른 과목의 표기
- 온라인/시간 미지정 과목의 표기
- 34교시 이후, PDF 2쪽 이후에 과목이 있는 경우
- 목록 형태(헤더가 있는 표)를 복사했을 때 나오는 텍스트 → 이 경우 요일·강의실이 들어 있을지도 모름
- "신청확인" 화면(최종 신청 내역)이 이 수강희망 화면과 같은 형태인지
